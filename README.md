# ReEDS: BAAJA permitting reform analysis (RFF)

This code was used to model the [Projected Effects of the Bipartisan American Affordability and Jobs Act on the Power Sector](https://www.rff.org/publications/issue-briefs/projected-effects-of-the-bipartisan-american-affordability-and-jobs-act-on-the-power-sector/).

This code branches from [ReEDS](https://github.com/ReEDS-Model/ReEDS) at commit [`43c4732d`](https://github.com/ReEDS-Model/ReEDS/commit/43c4732d) (July 15, 2026) and includes the changes in the [`pb/trans_op_merge`](https://github.com/ReEDS-Model/ReEDS/tree/b7c270fc) branch, along with other changes specific to this analysis.

The scenarios in the brief are defined in [`cases_baaja.csv`](cases_baaja.csv).
